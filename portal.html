DEVELOPER SUITE // API V3.3.0

Developer Portal & Telemetry Gateway

Selamat datang ke Portal Pembangun TesseraQS Core Architecture. Akses gerbang telemetri berdaulat C2, integrasi nodus Swarm, dan spesifikasi OpenAPI 3.1 rasmi.

Lihat OpenAPI 3.1 Spec (JSON) Polisi Keselamatan RFC 9116 Kertas Penyelidikan Senibina

📡 Senarai Endpoint Rasmi C2 Listener

1. Semakan Kesihatan Nodus

GET /health atau GET /status

curl -s https://tesseraqs.cloud-ip.cc/health
# Contoh Respons:
{
  "status": "ONLINE",
  "service": "OMEGA_C2_LISTENER",
  "version": "3.3.0",
  "node": "TELUK_INTAN_EDGE_01",
  "architecture": "TesseraQS Core",
  "timestamp": "2026-11-07T02:00:00+00:00",
  "uptime_seconds": 3600.0
}

2. Metrik Prometheus & Statistik Masa Nyata

GET /metrics • GET /telemetry/stats

# Metrik Prometheus format piawai:
curl -s https://tesseraqs.cloud-ip.cc/metrics

# Statistik operasi telemetri JSON:
curl -s https://tesseraqs.cloud-ip.cc/telemetry/stats

3. Penghantaran Niat Autonomi (Omni-Listener)

POST /omni-listener (Pengepala: Content-Type: application/json, X-Sovereign-Signature pilihan)

curl -X POST https://tesseraqs.cloud-ip.cc/omni-listener \
  -H "Content-Type: application/json" \
  -d '{"module": "dev_portal", "directive": "[DIRECTIVE: RECURSIVE SIMULATION]"}'

🛠️ Penggunaan Alat CLI Rasmi (tessera_cli.py)

# Semakan kesihatan nod
python3 tessera_cli.py health

# Mengambil metrik telemetri
python3 tessera_cli.py metrics --format json

# Menghantar direktif telemetri
python3 tessera_cli.py send --directive "[DIRECTIVE: RECURSIVE SIMULATION]"

# Audit keselamatan kedaulatan tempatan
python3 tessera_cli.py audit
