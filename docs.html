Portal ini mendokumentasikan spesifikasi antaramuka pengaturcaraan (API) bagi OMEGA C2 Telemetry Bridge & Autonomous Intent Executor. Kesemua endpoint beroperasi mengikut prinsip Dialektika Fraktal Rekursif YinYang.

GETHEAD/health  |  /status
Menyemak status kesihatan nod kedaulatan tempatan. Mengembalikan status ONLINE dan maklumat senibina.
{ "status": "ONLINE", "service": "OMEGA_C2_LISTENER", "version": "3.3.0", "node": "TELUK_INTAN_EDGE_01", "architecture": "TesseraQS Core", "uptime_seconds": 142.5 }
GETHEAD/ready
Kesiapsiagaan komponen nod (Readiness Probe). Mengesahkan integriti fail artifak teras dan kebolehcapaian direktori kerja modul.
{ "status": "READY", "node": "TELUK_INTAN_EDGE_01", "modules_dir_accessible": true, "core_artifacts_ready": true }
GETHEAD/health/detailed
Diagnostik mendalam nod, integriti kesemua 7 artifak pertahanan kriptografi, parameter rate-limiting, dan status anti-replay.
{ "status": "ONLINE", "sovereignty_level": "100% EMPIRICAL ACTIVE", "artifacts_integrity": { "c2_listener.py": true, "ca.crt": true, ... } }
GETHEAD/metrics
Eksposisi metrik masa nyata dalam format teks standard Prometheus, merangkumi bilangan permintaan, latensi, dan ralat.
omega_c2_uptime_seconds 142.5
omega_c2_requests_total 42
omega_c2_request_duration_seconds_sum 0.084
omega_c2_request_duration_seconds_count 42
GETHEAD/telemetry/stats
Statistik penggunaan masa nyata dan pecahan eksekusi intent autonomi dalam format JSON.
{ "status": "ONLINE", "metrics": { "total_requests": 42, "processed_telemetry": 15, "intents_executed": { ... } } }
POST/omni-listener
Enjin eksekusi niat autonomi C2. Memproses arahan pantas, pematerian Air-Gap, simulasi rekursif L2-L5, dan eskalasi Alpha. Menyokong tandatangan HMAC-SHA256 (X-Sovereign-Signature), tetingkap cap masa (X-Sovereign-Timestamp), dan keunikan nonce (X-Sovereign-Nonce).
POST /omni-listener HTTP/1.1
Content-Type: application/json
X-Sovereign-Signature: <hmac-sha256-hex>

{
  "directive": "[DIRECTIVE: RECURSIVE SIMULATION]",
  "module": "omega_swarm_command",
  "intent": "SWARM_DIRECTIVE"
}
